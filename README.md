# Strata

Strata is a personal project born out of a desire for unique wallpapers. Finding high-quality, specific styles of
topographic wallpapers online proved difficult, so I built this tool to generate them programmatically.

This repository represents a foundational version of the tool, which I intend to expand with more features and patterns
over time. It serves as both a functional utility and a portfolio piece demonstrating my frontend development skills.
